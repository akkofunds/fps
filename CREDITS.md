# Credits

## 3D weapon models

The first-person weapons in `public/models/` are modified versions of these Sketchfab models.
Changes: re-oriented and scaled to meters, parts regrouped for animation, gloved arms added, baked
reload / draw / fire / bolt / inspect animations added, textures resized to 1024 px WebP, meshes
compressed (see `tools/weapons`).
